\matlabtitle{Cinematica Diretta Manipolatore Sferico Tipo I}

\begin{par}
\begin{flushleft}
L'obiettivo della cinematica diretta è determinare la posizione e l'orientamento dell'organo terminale (end-effector) a partire dai valori delle variabili di giunto. Si utilizza la convenzione di Denavit-Hartenberg (DH) per modellare la geometria del robot. La convenzione di Denavit-Hartenberg è un metodo standard per assegnare sistemi di riferimento ai bracci di un robot. Per ogni braccio, si definiscono quattro parametri che descrivono la trasformazione geometrica rispetto al braccio precedente.
\end{flushleft}
\end{par}

\begin{par}
\begin{flushleft}
Si inizia definendo le variabili simboliche necessarie per i parametri DH. Questo permette di eseguire i calcoli in forma generale, senza dover specificare subito valori numerici. Successivamente, si assemblano questi parametri in una tabella dove ogni riga corrisponde a un link del robot e le colonne rappresentano i parametri $\left(\begin{array}{c}
\theta ,d,\alpha ,a
\end{array}\right)$.
\end{flushleft}
\end{par}

\begin{matlabcode}
clc; clear; close all;

% Definizione Variabili Simboliche
syms q1 q2 q3 real;
syms d1 real;

DH_table = [q1, d1, pi/2,  0;
            q2, 0,  -pi/2, 0;
            0,  q3, 0,     0];
% Numero Giunti Manipolatore
n = size(DH_table, 1);
\end{matlabcode}

\begin{par}
\begin{flushleft}
A partire dalla tabella DH, si può calcolare la matrice di trasformazione omogenea $^{i-1}A_i$ per ciascun link $i$. Questa matrice, di dimensioni $4\times 4$, rappresenta la trasformazione (rotazione e traslazione) dal sistema di riferimento del link $i$ a quello del link $i-1$. Si utilizza la funzione \texttt{Compute\_DH\_Transformations }per generare le matrici simboliche per ogni riga della tabella DH.
\end{flushleft}
\end{par}

\begin{matlabcode}
% Calcolo Matrici Trasformazione
[A_matrices, R_matrices] = Compute_DH_Transformations(DH_table);

% Visualizzazione Matrici Trasformazione
for i = 1:n
    fprintf('Matrice Di Trasformazione Omogenea ^(%d)A_(%d):\n', i-1, i);
    disp(A_matrices(:,:,i));
end
\end{matlabcode}

\newpage
\begin{par}
\begin{flushleft}
Per ottenere la posa dell'organo terminale rispetto alla base del robot, si moltiplicano in sequenza le matrici di trasformazione individuali. Il risultato è la matrice di trasformazione omogenea totale $^0 T_n$, che contiene sia la matrice di rotazione $^0 R_n$ (orientamento) sia il vettore di posizione $^0 P_{EE}$ dell'end-effector.
\end{flushleft}
\end{par}

\begin{par}
$$^0 T_3 = \,^0 A_1 \, \cdot \,{}^1 A_2 \, \cdot \,{}^{2} A_3$$
\end{par}

\begin{matlabcode}
% Calcolo Matrice Di Trasformazione Totale Dalla Base All'End Effector
T0n = A_matrices(:,:,1) * A_matrices(:,:,2) * A_matrices(:,:,3);
T0n = simplify(T0n);

fprintf('Matrice Di Trasformazione Omogenea Totale T03:\n');
disp(T0n);
\end{matlabcode}
\begin{matlaboutput}
Matrice Di Trasformazione Omogenea Totale T03:
\end{matlaboutput}
\begin{matlabsymbolicoutput}
\hskip1em $\displaystyle \left(\begin{array}{cccc}
\cos\left(q_1 \right)\,\cos\left(q_2 \right) & -\sin\left(q_1 \right) & -\cos\left(q_1 \right)\,\sin\left(q_2 \right) & -q_3 \,\cos\left(q_1 \right)\,\sin\left(q_2 \right)\\
\cos\left(q_2 \right)\,\sin\left(q_1 \right) & \cos\left(q_1 \right) & -\sin\left(q_1 \right)\,\sin\left(q_2 \right) & -q_3 \,\sin\left(q_1 \right)\,\sin\left(q_2 \right)\\
\sin\left(q_2 \right) & 0 & \cos\left(q_2 \right) & d_1 +q_3 \,\cos\left(q_2 \right)\\
0 & 0 & 0 & 1
\end{array}\right)$
\end{matlabsymbolicoutput}
\begin{par}
\begin{flushleft}
Dalla matrice totale $^0 T_n$ si può estrarre la sottomatrice di rotazione $3\times 3$ e il vettore di posizione $3\times 1$.
\end{flushleft}
\end{par}

\begin{matlabcode}
% Matrice Di Rotazione R03
R0n = T0n(1:3, 1:3);
R0n = simplify(R0n);
fprintf('Matrice Di Rotazione R03:\n');
disp(R0n);
\end{matlabcode}

\begin{par}
\newpage
\begin{flushleft}
Per visualizzare una configurazione specifica del robot sono necessari dei valori numerici. Si sostituiscono ora le variabili simboliche (angoli di giunto e parametri geometrici) con valori numerici.
\end{flushleft}
\end{par}

\begin{matlabcode}
% Lista Variabili Simboliche Da Sostituire
varsToSub = [q1, q2, q3, d1];

% Lista Valori Numerici Corrispondenti
% Esempio: q1=30°, q2=45°, q3=0.5 m, d1=1 m
numValues = [pi/6, pi/4, 0.5, 1];

% Sostituzione Valori
A_Num = zeros(4, 4, n);
for i = 1:n
    A_Num(:,:,i) = double(subs(A_matrices(:,:,i), varsToSub, numValues));
end

% Calcolo Matrice Numerica
T0n_Num = double(subs(T0n, varsToSub, numValues));
fprintf('Matrice Di Trasformazione Totale Numerica T03:\n');
disp(T0n_Num);
\end{matlabcode}

\matlabheading{Visualizzazione Grafica Manipolatore Sferico Tipo I}

\begin{matlabcode}
fig_name    = 'Configurazione Manipolatore Sferico Tipo I';
arrow_scale = 0.18;
view_angles = [45, 25];
labels      = {'Terna 0 (Base)', 'Terna 1', 'Terna 2', 'Terna 3 (EE)'};

figure('Name', fig_name, 'Color', 'w');
hold on;
grid on;
box on;
xlabel('X [m]', 'FontWeight', 'bold');
ylabel('Y [m]', 'FontWeight', 'bold');
zlabel('Z [m]', 'FontWeight', 'bold');
view(view_angles(1), view_angles(2));
axis equal;

% 1. Calcolo di Tutte le Posizioni e Orientamenti (Base + n Giunti)
T_cumulative = eye(4);
positions = zeros(n+1, 3);
R_all     = zeros(3, 3, n+1);

positions(1, :) = T_cumulative(1:3, 4).';
R_all(:, :, 1)  = T_cumulative(1:3, 1:3);

for i = 1:n
    T_cumulative = T_cumulative * double(A_Num(:, :, i));
    positions(i+1, :) = T_cumulative(1:3, 4).';
    R_all(:, :, i+1)  = T_cumulative(1:3, 1:3);
end
\end{matlabcode}
\newpage
\begin{matlabcode}
% 2. Disegno Bracci
h_link = plot3(positions(:,1), positions(:,2), positions(:,3), '-', 'Color', [0.25 0.25 0.25], ...
    'LineWidth', 2.5);
% 3. Evidenziazione Giunti Meccanici ed End-Effector
h_base = plot3(positions(1,1), positions(1,2), positions(1,3), 's', 'MarkerSize', 8, ...
    'MarkerFaceColor', [0.4 0.4 0.4], 'MarkerEdgeColor', 'k');
h_joints = plot3(positions(2:end-1,1), positions(2:end-1,2), positions(2:end-1,3), 'o', ...
    'MarkerSize', 6, 'MarkerFaceColor', 'k', 'MarkerEdgeColor', 'k');
h_ee = plot3(positions(end,1), positions(end,2), positions(end,3), 'p', ...
    'MarkerSize', 10, 'MarkerFaceColor', [0.95 0.75 0.1], 'MarkerEdgeColor', 'k');

% 4. Disegno delle Terne di Riferimento DH (X=Rosso, Y=Verde, Z=Blu)
col_X = [0.85, 0.15, 0.15];
col_Y = [0.15, 0.65, 0.20];
col_Z = [0.15, 0.35, 0.85];

h_axes = gobjects(1, 3);
for i = 1:(n+1)
    p = positions(i, :);
    R = R_all(:, :, i);
    qx = quiver3(p(1), p(2), p(3), R(1,1)*arrow_scale, R(2,1)*arrow_scale, R(3,1)*arrow_scale, 0, ...
        'Color', col_X, 'LineWidth', 1.8, 'MaxHeadSize', 0.35);
    qy = quiver3(p(1), p(2), p(3), R(1,2)*arrow_scale, R(2,2)*arrow_scale, R(3,2)*arrow_scale, 0, ...
        'Color', col_Y, 'LineWidth', 1.8, 'MaxHeadSize', 0.35);
    qz = quiver3(p(1), p(2), p(3), R(1,3)*arrow_scale, R(2,3)*arrow_scale, R(3,3)*arrow_scale, 0, ...
        'Color', col_Z, 'LineWidth', 1.8, 'MaxHeadSize', 0.35);
    if i == 1
        h_axes(1) = qx;
        h_axes(2) = qy;
        h_axes(3) = qz;
    end
end
% 5. Etichette Origini
visited = false(n+1, 1);
for i = 1:(n+1)
    if visited(i)
        continue;
    end
    dists = sqrt(sum((positions - positions(i, :)).^2, 2));
    coincident_idx = find(dists < 1e-4);
    visited(coincident_idx) = true;
    combined_label = strjoin(labels(coincident_idx), ' / ');
    p = positions(i, :);
    text(p(1), p(2), p(3) + 0.18*arrow_scale, sprintf(' %s', combined_label), ...
        'FontSize', 9, 'FontWeight', 'bold', ...
        'BackgroundColor', [1 1 1], 'EdgeColor', [0.8 0.8 0.8], 'Margin', 1);
end
% 6. Margine di Visualizzazione Attorno al Robot
all_pts = [positions; positions + arrow_scale; positions - arrow_scale];
min_xyz = min(all_pts, [], 1);
max_xyz = max(all_pts, [], 1);
span = max(max_xyz - min_xyz);
if span == 0, span = 1; end
margin = 0.15 * span;
xlim([min_xyz(1) - margin, max_xyz(1) + margin]);
ylim([min_xyz(2) - margin, max_xyz(2) + margin]);
zlim([min_xyz(3) - margin, max_xyz(3) + margin]);

% 7. Legenda e Titolo
legend([h_axes(1), h_axes(2), h_axes(3), h_link, h_base, h_joints, h_ee], ...
    {'Asse X', 'Asse Y', 'Asse Z', 'Bracci (Link)', 'Base', 'Giunti', 'End-Effector'}, ...
    'Location', 'bestoutside');
title(fig_name, 'FontSize', 12, 'FontWeight', 'bold');
hold off;
\end{matlabcode}
